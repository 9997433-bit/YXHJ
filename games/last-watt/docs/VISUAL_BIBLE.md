## 1. 优先级与术语

- **丢弃优先级（GDD 15.3）**：`事件 > combo > 环境氛围`。超预算时从最低级丢起；**事件类 combo 粒子永不降级、永不丢弃**。
- **效果类别**：`事件`（一次性、有屏幕冲击）/ `combo 态`（combo 产生的持续状态）/ `循环`（塔攻击、涂层等常驻）/ `环境`（氛围，最先被砍）。
- **自发光档位**：E0=0 熄灭 / E1=1.2 待机 / E2=2.5 活跃 / E3=5.0 事件（实施建议）。
- **震动档位**：无 / 轻（0.2–0.3s，约 0.15% 屏高振幅）/ 中（0.3s，约 0.4% 屏高振幅，**全游戏最大档 = 拆迁蟹自爆**）。无「重」档，不许新增。
- **里程碑列**：M1 / M2 / M3 对应 GDD 第 19 章范围。

## 2. 颜色立法 → 代码常量

单一真源：调色板常量类 + 同名 ScriptableObject，全项目禁止散落硬编码颜色。

```csharp
// VfxPalette.cs —— 六大立法色（GDD 15.2），sRGB 值，使用时注意线性空间转换
public static class VfxPalette
{
    public static readonly Color ElectricCyan = FromHex("35E0FF"); // 电青：电力/导电/超载/大招/电力UI
    public static readonly Color FireOrange   = FromHex("FF7A29"); // 橙红：火/点燃/自爆/引信/裂隙
    public static readonly Color IceWhite     = FromHex("BFF7FF"); // 冰白：冰/冻结/碎裂/冷凝雾
    public static readonly Color ScorchBrown  = FromHex("6B4A2B"); // 焦褐：油渍/尘土/土块（永不自发光）
    public static readonly Color CoinGold     = FromHex("FFD84D"); // 金黄：金币/赏金
    public static readonly Color AlertRed     = FromHex("FF3B30"); // 警红：丢区/核心受损/非法操作/缺口
}
```

**执行断言（编辑器校验脚本，实施建议）**：
- [ ] 扫描所有粒子/贴花材质：粒子贴图必须为灰度，tint 颜色必须引用 `VfxPalette`。
- [ ] 扫描所有自发光材质：emissive 颜色必须为立法色或白色（闪白），焦褐永不出现在 emissive 通道。
- [ ] 环境贴图审计：饱和度 >40% 像素占比超阈值即报警（T3 色板审计的离线版）。

## 5. 预算硬约束与执行机制

### 5.1 预算表（GDD 15.3 原文，程序断言）

| 预算项 | 上限 | 执行机制 |
|---|---|---|
| 同屏活跃发射器 | **≤64**（循环 ≤24，一次性 ≤40） | `VfxGovernor` 注册制：所有发射器经其生成/回收；超限按 `事件>combo>环境` 丢最低级 |
| GPU 粒子总量 | **≤20,000** | 全 VFX Graph GPU 模拟，CPU 粒子零使用；按 §4 峰值预算离线求和 + 运行时计数 HUD |
| 动态点光 | **≤8** | `LightPool` 分配表（见 5.2）；申请失败自动降为加法混合面片伪光 |
| 粒子材质 | **≤12 种，1 张 1024 图集** | 构建期校验：粒子材质引用图集外贴图即报错 |
| 贴花 | **≤64 张，1 张 512 图集** | `DecalPool` 环形池，超出淘汰最旧 |
| 对象池 | 高频一次性效果预热 8–16 实例 | 运行期 `Instantiate` 调用计数断言 = 0（战斗中） |

## 6. 屏幕冲击节流器（ScreenImpactThrottler）

顿帧/闪光/震动的**唯一入口**，任何效果不得自行改 timeScale、闪屏或晃摄像机。

```csharp
ScreenImpact.Request(new ImpactRequest {
    hitstopMs = 60,          // 顿帧毫秒；0 = 无
    flash     = FlashKind.White1Frame,  // 白闪/青闪/橙闪/无
    shake     = ShakeTier.None          // 无/轻/中
});
```

**裁决规则（GDD 15.2 防糊规则 ①，硬性）**：
- [ ] 顿帧：全局 100ms 窗口内最多执行 1 次；后到的**直接丢弃，不排队补发**。
- [ ] 震动：不叠加，同时请求取最大档；全游戏最大档 = 中（拆迁蟹自爆）。
- [ ] 全屏闪：同 100ms 窗口去重（实施建议，初稿可调）；局部白闪（单位材质闪白）不受节流。
- [ ] 慢放（波 3 冰碎首触发 0.5s 全局慢放）也从本入口走，与顿帧互斥期间以慢放为准。

## 7. 防糊规则落地（GDD 15.2 三条硬规则 ②③）

- [ ] **持续状态只许「材质变化 + 极少量粒子」**：状态类单目标活跃粒子 ≤12（冻结霜花 12、湿 2、点燃 12、油渍 3/格 均达标）；大粒子量只给瞬间事件。
- [ ] **渲染层级表**（低→高）：地面贴花 → 地面循环粒子（油渍冒泡/火场底） → 单位 → 单位状态与事件粒子 → **血条/状态图标环** → 世界空间提示（塔黄框/推荐格高亮） → 屏幕 UI。**所有粒子画在血条之下**，用 sorting layer 强制，禁止逐效果自定义。
- [ ] **同类循环发射器 >10 个**：该类发射率减半 + 隔帧更新（`VfxGovernor` 按 ID 前缀分类计数自动执行）。

## 8. 降级阶梯（GDD 15.3，未达 60fps 时按序执行）

| 档 | 动作 | 恢复条件（实施建议） |
|---|---|---|
| D1 | 关环境氛围粒子（`vfx_ambient_vent` 等环境类全停） | 连续 5s ≥60fps 回升一档 |
| D2 | 循环特效发射率再减半（冷凝雾/火场/曳光） | 同上 |
| D3 | 贴花上限 64→32，加速淘汰 | 同上 |
| D4 | 动态点光 8→4（火场配额先砍） | 同上 |

**永不降级清单**：`vfx_ice_shatter`、`vfx_conduct_boost`、`vfx_ignite` 触发瞬间、`vfx_overload` 激活演出、`vfx_ultimate`、`vfx_crab_explode`、`vfx_zone_lost`——事件类 combo 粒子是玩法反馈，掉帧也不许砍。UI 发光走烘焙贴图，天然不受降级影响。

## 9. 灯光与后处理配置单（URP，实施建议，初稿可调）

- [ ] 方向光 1 盏：固定角度（与摄像机呈约 35° 夹角侧上方），无实时阴影或仅硬阴影一档；无昼夜。
- [ ] Bloom：threshold 1.1（线性）、intensity 0.6、scatter 0.5、无 tint；albedo 资产亮度 ≤0.85 由资产验收保证（prompts 文档 T1）。
- [ ] Vignette（事件驱动，平时 0）：丢区 = 警红，2s 内 0→0.35→0；大招 = 电青，1.5s 内 0→0.25→0；核心受损跳分 = 警红 0.2 脉冲 0.3s。
- [ ] 色调映射：Neutral。除此三件外不开任何 Volume 效果。
- [ ] 自发光档位 E0/E1/E2/E3 = 0/1.2/2.5/5.0，做成材质属性预设，全项目引用。

## 10. M1 必做视觉切片（「冰碎能爽到」）

对照 GDD 19.M1 验收：60fps 恒定；冰碎首触发「看+听」反馈链（慢放/提示条/粒子/音效）无遗漏。以下四项为 **P0 验收切片**。

### 10.1 冰碎三重反馈（P0，本切片的灵魂）

完整链路，缺一环即验收失败：

1. **叠层**：冷凝雾持续命中 → 敌身表面高光上调（湿），每 0.5s 叠 1 层湿冷。
2. **冻结**：3 层 → 材质切**冰壳着色器**（冰白 fresnel）+ 12 粒霜花，0.3s 演出。
3. **碎裂**：破碎锤单发 ≥40 命中冻结目标 → **同帧**触发：
   - 粒子：24 粒硬边冰晶带重力旋转炸开 + 霜痕贴花 3s（贴花池）；
   - 音效：玻璃碎裂「咔嚓」（事件音效表同帧）；
   - 顿帧：60ms（节流器入口）+ 白闪 1 帧。
4. **首次触发教学链**（波 3）：全局慢放 0.5s + 高亮破碎锤图纸 + 一次性提示条「冻结的敌人怕重击」。

**验收**：粒子/音效/顿帧三通道同帧（误差 ≤1 帧）；关声音仅看画面、关画面仅听声音均能确认碎裂发生；冰碎池预热 8、运行期零 Instantiate；灰度截图下冰晶（硬边多面体）与任何电系火花可区分。

### 10.2 冷凝雾（P0，循环特效的标杆）

- 锥形低速半透明冷雾：软圆粒子，冰白 tint、α 0.15–0.35，循环发射，峰值 ≤150/塔。
- 属循环预算（≤24 循环发射器）；同屏冷凝塔 >10 时发射率自动减半 + 隔帧更新。
- 塔停机/断电时雾流 0.2s 内收干（发射停止 + 存活粒子自然消亡），指示灯 E0。

**验收**：雾不遮血条不糊轮廓（层级在血条之下）；T2 灰度测试下雾与黑烟可区分（雾更亮更软）；6 塔齐喷参照机不掉帧。

### 10.3 破碎锤打击（P0，无震屏的打击感）

- 节奏：液压蓄力 0.3s（液压杆压缩，可读的「要砸了」预告）→ 砸地瞬间：目标材质闪白 1 帧 + 焦褐尘土扇 6–8 粒 + 贴地冲击环 0.2s + 重击音。
- **不使用屏幕震动与顿帧**（打击感来自动画节奏 + 闪白 + 音效）；只有命中冻结目标升级为冰碎时才吃 §10.1 的事件冲击。
- 升级「震荡波」（M2）复用冲击环放大版。

**验收**：连续攻击 2.5s 节拍清晰可读；尘土为焦褐非白色（不与冰雾混淆）；打击帧与音效帧对齐（≤1 帧）。

### 10.4 供电/储能自发光 UI（P0，电即经济的可视化）

- **供电条**（左上）：分格横条，1 格 = 1 点供电；已用格电青实心发光（烘焙 glow），空闲格暗底细描边。空闲格即充能来源——以 1Hz 呼吸微光提示「空闲供电在给储能充电」（实施建议）。
- **缺口反馈**：尝试建造超上限 → 超出格数警红闪 2 次 + 驳回音；建造菜单耗电塔灰显 + 警红缺口数。
- **储能环**（0–100）：环形电青填充；20 刻度点（超载门槛）常亮细刻；满 100 时 1Hz 轻脉冲（亮度 +20%）；超载消耗 20 → 0.3s 扇形扫退 + 短残影。
- 实现：Screen Space Overlay，发光用九宫格 glow 贴图 + 加法层，**不依赖后处理 Bloom**，降级不影响 UI。

**验收**：不看数字仅看条/环即可回答「还能建几点电的塔」「储能够不够一次超载」；灰显/缺口/驳回三态在 T2 灰度下仍可辨；发光元素通过 T1 关灯测试（UI 自发光与场景 Bloom 解耦）。

### 10.5 M1 支撑项（P1，随 M1 范围顺带落地）

机枪曳光 `vfx_muzzle_tracer`、命中火花 `vfx_hit_spark`、油渍贴花+冒泡 `vfx_oil_decal`、湿状态 `vfx_wet_status`、受击闪白、死亡溶解 `vfx_death_dissolve`、挖沟施工 `vfx_dig`（含进度环）、漏怪抢金币 `vfx_coin_steal` + 完整度扣分红跳字、金币入账飘字。
