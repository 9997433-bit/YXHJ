## 0. 判定规则

1. **硬门槛**：下表所有标注「门槛」的条目必须全部通过，M1 才算通过。标注「记录」的条目只需产出基线数据留档，不卡合并。
2. **一票否决红线**（源自 GDD 第 20 章，任一违反直接打回，不允许用变通手段绕过）：
   - **教学红线**（G-09）：5 人试玩 <4 人过波 5 → 重做教学节拍，**不准靠加文字说明糊**；
   - **事件粒子永不降级**（V-03）：任何负载下冰碎事件粒子被节流/降级即打回；
   - **范围回潮**（S-01 / S-03 / S-05）：英雄、无尽、天气等 v1 外系统出现任何代码接入即打回，附录 A 前置条件未达成不开工；
   - **GDD 锁定**（S-07）：`docs/GDD-余电.md` 出现任何 diff 即打回。
3. **测法图例**：✅ 全自动（CI 可跑）；◐ 半自动（自动采数 + 人工判定）；✋ 纯人工（试玩/目检）。
4. 涉及具体数值（塔价、伤害、冻结时长等）以 `games/last-watt/data/**` 配表与 `SYSTEMS.md` 为准；本清单只锁**行为与阈值**，不复制数值。
