## 0. 三句话总纲（所有人先读）

1. **锈铁废土是「死」的**：低饱和、哑光、无自发光，连场景里的灯具都全部熄灭。
2. **电是唯一「活」的东西**：电弧、超载、火场、塔的供电指示灯、UI 描边——**凡发光必是信息**，Bloom 只吃自发光。
3. **粒子是战场语言，不是烟花**：每一粒都在回答「刚才发生了什么」；回答不了这个问题的粒子，删掉。

## 2. 色板立法

### 2.1 六大立法色（GDD 15.2 原文，不可改）

| 名称 | HEX | RGB | 自发光 | 辖区（只许出现在） | 禁区 |
|---|---|---|---|---|---|
| 电青 | `#35E0FF` | 53,224,255 | ✓ | 电力/导电/超载/大招/供电与储能 UI/建造合法提示 | 环境贴图、非电系统 |
| 橙红 | `#FF7A29` | 255,122,41 | ✓ | 火/点燃/火场/自爆/拆迁蟹引信/利维坦 P3/地热裂隙微光 | UI 常规元素、环境静物 |
| 冰白 | `#BFF7FF` | 191,247,255 | ✓（仅事件瞬间） | 冰/冻结冰壳/碎裂冰晶/霜痕/冷凝雾 | 火电油任何系统 |
| 焦褐 | `#6B4A2B` | 107,74,43 | ✗ | 油渍/尘土/土块/黑烟基调 | 一切发光通道 |
| 金黄 | `#FFD84D` | 255,216,77 | ✓ | 金币/赏金飘字/波次奖励 | 警示、状态、环境 |
| 警红 | `#FF3B30` | 255,59,48 | ✓ | 丢区/核心受损/警戒虚线/非法操作/电力缺口 | 伤害数字以外的常规 UI |

### 2.2 环境底色（非立法，实施建议，初稿可调）

环境贴图只从下表取色再做脏化磨损；**饱和度 ≤40%、明度 ≤70%**，不得进入六立法色任何一个的高饱和邻域。

| 名称 | HEX | 用途 |
|---|---|---|
| 沥青黑 | `#15181D` | 路面基调、阴影暗部、UI 面板底 |
| 铁灰 | `#3C434B` | 机械结构、塔身金属 |
| 锈棕 | `#7C4A2A` | 锈蚀铁皮主色（哑光，永不发光） |
| 锈亮部 | `#A3623B` | 锈的受光面、边缘磨损 |
| 混凝土灰 | `#8A8478` | 地基格、基座、掩体 |
| 干土黄灰 | `#9B8A66` | 软土格、尘土地表 |
| 暗水青灰 | `#2E4A50` | 水面/水洼基调（低饱和，与电青靠饱和度与发光区分） |
| 褪色警示黄 | `#8F7A35` | 机械上的旧警示条纹漆（哑光脏化，与金币靠明度与发光区分） |

### 2.3 用色三规则

1. **粒子贴图与 VFX 面片一律灰度作画，运行时由发射器按立法色着色**——从管线上杜绝私自调色。
2. **同色不同系统靠形状区分**（GDD 形状立法）：冰=硬边多面体碎片；火=软边翻页火舌；电=折线与尖刺火花；超载=扩散圆环；经济=圆点飞行流。
3. **场景中所有环境灯具道具（探照灯、路灯、旧配电箱指示灯）一律做成熄灭状态**。全图会发光的只有：玩家电网（塔/发电机/核心/UI）、火、以及被立法允许的威胁信号（拆迁蟹引信、利维坦 P3、地热裂隙微光）。

## 3. 摄像机与可读性规格

- 透视 FOV 30°、俯角 55°、朝向固定；缩放两档；逻辑纯 2D 网格 20×12，仅表现层 3D。
- **剪影目标（实施建议，初稿可调）**：1080p 远档下一格约 ≥48px；敌人剪影须在 34px 高度内可辨类别；8 塔纯黑剪影互不混淆。
- **飞行单位必须带地面投影圆斑**（blob shadow），否则斜俯视下高度不可读。
- 所有资产验收都在**游戏内摄像机的两档缩放**下截图评审，不看 DCC 软件里的自由视角美图。

## 4. 光照与 Bloom 契约

这是全项目视觉的地基条款，任何资产、着色器、后处理改动不得破坏：

1. **1 盏固定方向光 + 动态点光全局 ≤8 盏**（电弧、火场、Boss 专用）；超预算的「光」用加法混合面片伪造；AO 一律烘焙。
2. **Bloom 高阈值只吃自发光**。实施建议（初稿可调）：线性空间 Bloom 阈值 1.1；albedo 贴图最大亮度 ≤0.85，物理上永远过不了阈值。
3. **自发光强度四档**（实施建议，初稿可调）：

| 档位 | HDR 强度 | 语义 |
|---|---|---|
| E0 | 0 | 熄灭（停机、断电、丢区） |
| E1 | 1.2 | 待机（供电指示灯、地热裂隙、微弱呼吸） |
| E2 | 2.5 | 活跃（攻击中、充能中、火苗） |
| E3 | 5.0 | 事件（超载、大招、爆炸闪光、冰碎白闪） |

4. 后处理只有三件：Bloom、事件驱动 Vignette（丢区/大招染色）、轻量色调映射。**没了**——不加任何滤镜、光晕、色差。

## 5. 分资产提示词

### 5.1 场景地块（6 种）与道具（10 个）

通用：低模块、AO 烘焙、环境底色表取色、无自发光。每种地块 1 模型 + 2 贴图变体。

| 地块 | 提示词要点 |
|---|---|
| 路面 | 压实土 + 铁板拼接，车辙与履带痕；**水洼变体**：路面凹陷积水，镜面高光走反射不走自发光 |
| 平地（地基） | 混凝土浇筑格，边缘外露螺栓与钢筋头；建造时的电青描边由运行时叠加，不画进贴图 |
| 水面 | 暗水青灰双层滚动（着色器实现），岸线泡沫亮线非自发光 |
| 沟壑 | 深色断层岩壁，底部渐入沥青黑，让「不可通行」一眼可读 |
| 软土 | 龟裂干土 + 碎石，明度比路面高一档，与路面在灰度下也能区分 |
| 桥 | 玩家造物：更「新」的钢板 + 脚手架护边 + 可见焊缝，与废土旧物形成新旧对比 |

道具 10 个（管道、废铁堆、地热喷口、冷却塔残骸、电缆卷轴、护栏、龙门吊残臂、旧配电箱、熄灭的探照灯杆、轮胎沙袋堆）：200–400 面；地热喷口自带循环蒸汽粒子（环境预算类）；**所有灯具做熄灭态**。

### 5.2 塔与发电机（8 条一句话提示）

通用：300–800 面，平面着色，炮塔水平转向分件，自发光遮罩只覆盖灯/线圈/液位。
**指示灯立法：占电 >0 的塔才有电青供电指示灯（通电 E1 / 攻击 E2 / 停机 E0）；占电 0 的塔无灯**——让「发光 = 正在耗电」成为一眼可读的真话。

| 塔 | 提示词 |
|---|---|
| 铆钉机枪（占电 0） | 矮壮双足底座 + 单管铆钉炮，锈棕装甲拼接，无发光件，纯机械感 |
| 焦油喷洒器（占电 0） | 圆桶罐体 + 旋转洒头，桶身焦褐油渍垂痕，无发光件 |
| 液压破碎锤（占电 1） | 液压臂 + 配重锤头，蓄力时液压杆可见收缩，底座 1 枚电青小灯 |
| 冷凝喷射塔（占电 2） | 保温罐体 + 锥形喷口，罐沿结霜白边（冰白低饱和、非发光），2 枚电青灯 |
| 火焰喷射塔（占电 2） | 燃料罐 + 点火喷嘴，罐身褪色警示黄条纹，喷嘴常明橙红小引火苗（E1） |
| 特斯拉线圈（占电 4） | 全场最高剪影：绝缘瓷瓶塔架 + 顶端球极，待机顶球电青 E1、攻击 E2 |
| 电容站（占电 0，用储能） | 无炮管：一组竖直电容柱 + 仪表盘，储能量以柱身电青自发光液位显示，超载时液位蓝→红渐变 |
| 发电机（建筑） | 地热井架 + 涡轮机壳 + 转动飞轮，烟囱小股白蒸汽循环，输出指示灯电青 E1 |

### 5.3 敌人（8 条一句话提示）

通用：200–500 面；动画只做走/死；受击=材质闪白；死亡=溶解着色器+零件粒子。
**敌方机体默认零自发光**；只有「威胁进度」允许发光（拆迁蟹引信、利维坦 P3），保证发光语言不被污染。

| 敌人 | 提示词 |
|---|---|
| 拾荒虫 | 六足小型机械虫，背负废铁篓，锈棕主色 |
| 疾行鼠群 | 低矮流线四足机体，小剪影、群体感，轮足混合 |
| 装甲运输车 | 履带方壳，铆接装甲板层叠，体块厚重压地 |
| 侦察蜂 | 四旋翼小机体 + 垂尾传感器，必配地面投影圆斑 |
| 拆迁蟹（爆破工兵） | 大螯 + 腹部炸药桶，桶身橙红警示条纹，引信灯橙红闪烁（唯一允许发光的常规敌人件） |
| 修理无人机 | 悬浮工蜂机体 + 折叠机械臂，头顶扳手图标（UI 层）常驻，脚下褪色黄非饱和光环圈（非立法色新增，初稿可调） |
| 修理母舰（小 Boss） | 大型悬浮平台 + 多条下垂机械臂，腹部无人机挂架可见 |
| 利维坦（大 Boss） | 巨型采掘机：P1 全身可打落的装甲板层；P3 过载冲刺时全身管线转橙红发光 E3——它此刻变成场上最亮的「光源级威胁」 |

### 5.4 粒子图集（给粒子图作者，1 张 1024×1024）

**铁律：全部灰度作画（白色 + alpha），无内嵌颜色；12 种粒子材质全部取自这一张图集**（保证合批）。硬边元素 alpha 不许羽化，软边元素不许出现硬边。布局建议（初稿可调）：

| 图集元素 | 数量/规格 | 形状语言 |
|---|---|---|
| 火花 | 4 变体 | 尖刺折线碎片，硬边（电系） |
| 软烟 | 3 变体 | 大软圆渐变（黑烟/蒸汽/尘雾共用） |
| 火焰翻页 | 4×4 帧（256² 子块） | 软边火舌；**这是全项目唯一允许的翻页子块**，只用于点燃火舌 |
| 冰晶 | 6 变体 | 硬边多面体碎片，切面分明（冰系） |
| 电辉点 | 2 变体 | 中心过曝小点 + 十字辉 |
| 软圆 | 2 变体 | 冷凝雾/光雾底 |
| 环 | 2 变体 | 细环（扩散冲击环）+ 粗环（进度环） |
| 土块 | 4 变体 | 硬边不规则块（施工/尘土） |

投射物一律纯粒子顶替贴图：机枪曳光=拉伸粒子、火焰喷射=软粒子流、冷凝雾=软圆、电弧=LineRenderer+噪声、施工尘土=土块+软烟。**除图集内的火舌翻页子块外，不画任何帧动画贴图**。

### 5.5 贴花图集（1 张 512×512）

油渍 ×3 变体、霜痕 ×2、焦痕 ×2、电纹 ×2、警戒虚线（可平铺条带）。同样灰度作画运行时着色（油=焦褐、霜=冰白、电纹=电青、警戒=警红）。全局贴花上限 64 张，超出淘汰最旧。

### 5.6 着色器（4 个，行为规格）

| 着色器 | 行为规格 |
|---|---|
| 自发光主材质 | albedo（统一色板贴图）+ 自发光遮罩 + **实例级** 自发光颜色/强度属性，可被脚本驱动：受击闪白、超载蓝→红、停机熄灭（E0–E3 档位见 §4） |
| 冰壳 | 覆盖敌人材质的顶层：冰白 fresnel 边缘光 + 噪声高光，不透明度约 0.9，无需折射 |
| 溶解 | 噪声阈值溶解 0.6s，溶解边缘 1–2px 电青自发光，配少量零件粒子 |
| 水面滚动 | 双层 UV 滚动（第二层反向 0.7× 速度），高光走镜面通道，**不进自发光** |

另有一个材质行为（不占 4 个着色器名额，做进主材质变体）：「湿」状态 = 表面光滑度/高光上调，不加发光。全部着色器须 SRP Batcher 兼容。

### 5.7 UI（扁平矢量 + 发光描边）

- 面板底：沥青黑 `#15181D` 约 80% 不透明度；描边电青 1–2px + **烘焙 glow 贴图**（九宫格）实现发光——UI 走 Screen Space Overlay 不过后处理，发光效果不依赖 Bloom，保证任何降级下 UI 可读。
- **图标形状与粒子语言同源**：冰图标=多面体碎片形、火=火舌形、电=折线火花形、超载=同心圆环、金币=圆点。状态图标 5 个（湿/油/冻/燃/扳手）同规则。
- 数字用等宽字体（跳字不抖动）；金币金黄、供电与储能电青、警报与缺口警红、完整度条白灰底 + 警红阈值刻度线（80/50）。
- 电力不足时耗电塔图标灰显 + 警红缺口数；充能满的大招按钮电青脉冲。

## 6. 「粒子是战场语言」写作法

新增或修改任何粒子效果，先书面回答三问，答不出任何一问即不立项：

1. **谁触发了它？**（映射到哪个玩法事件）
2. **玩家从中读到什么？**（一句话，如「这只怪现在怕重击」）
3. **它多久后消失、怎么消失？**（持续状态只许「材质变化 + 极少量粒子」，大粒子量只给瞬间事件）

**烟花禁令**：禁止「为了好看」的环绕光点、常驻辉光、庆祝式喷射。华丽度预算全部倾斜给四大 combo 的**事件瞬间**——那是玩家操作的回报时刻，也是唯一允许「爽过头」的地方。

## 7. 验收语言

### 7.1 全局四测试（每次里程碑评审必跑）

| 测试 | 操作 | 通过标准 |
|---|---|---|
| T1 关灯测试 | 关闭 Bloom 截图 / 打开 Bloom 截图 | 关闭后画面依旧完整可读；打开后**只有**自发光元素泛光，任何 albedo 像素不得泛光 |
| T2 灰度测试 | 战斗截图转灰度 | 四 combo、丢区、施工、血条仍靠**形状**可辨认 |
| T3 色板审计 | 截图提取饱和度 >60% 的像素 | 全部落在六立法色 ±容差内；环境不得贡献高饱和像素 |
| T4 预算压力 | VFX Gym 最坏场景（见 VISUAL_BIBLE §11） | 参照机 60fps；发射器/粒子/贴花/点光计数全程不超限 |

### 7.2 分类验收清单

**场景资产**
- [ ] 置入标准场景后高饱和像素占比 <5%（环境是「死」的）
- [ ] 自发光通道为空（地热裂隙、核心等立法许可项除外）
- [ ] 两档缩放下地块类型肉眼可辨且通过灰度测试
