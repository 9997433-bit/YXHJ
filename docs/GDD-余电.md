> 状态：v1 范围已锁定。本文档为唯一正文，取代此前 v0.1 / v0.2 / v0.3 三份方案。
> 除标注「初稿可调」的数值外，系统裁决不再开放讨论；未决项已在文中拍板。
> v0.2 战斗英雄方案压缩收录于附录 A，属 v1.5 候选，不在 v1 范围内。

## 1. 一句话定位与玩家体验承诺

**2.5D 斜俯视网格塔防：你守的不是城堡，是末世最后一座地热发电站——电既是你的经济，也是你的武器。**

与常见塔防的三点差异：

1. **路径可挖可架**：有限次数的挖沟/搭桥工程操作，防线布局是持续博弈而非开局定型。
2. **元素反应少而明确**：只有 4 个 combo（冰碎、油火、导电、超载），全部写在 UI 上，粒子特效即战场语言。
3. **漏怪丢的是电网，不是命**：漏怪扣完整度、丢变电区断电，压力滚动累积，不会一只怪进门就 Game Over。

**玩家体验承诺**（验收时对照）：

- 每 30 秒都有一个值得想 3 秒的决定；
- 第一次打出每个 combo 时，不看说明也知道发生了什么（粒子 + 音效 + 顿帧三重反馈）；
- 波 10 之后一定会被迫拆改自己前 10 波的布局；
- 输了知道输在哪一波、哪个口。

## 2. 核心循环与一局结构

### 2.1 每 30 秒玩家在做什么（按频率排序）

1. **波间（暂停态）**：看下一波兵种预览 → 在「造新塔 / 升级 / 挖沟改路 / 攒钱」四选一；决定是否提前开波换 +10% 金币。
2. **波中**：电容站超载放在哪一坨塔、什么时机点；治疗无人机和拆迁蟹出现时切换塔的目标优先级。
3. **每 5 波**：大招「主控过载」充能满，决定这口爆发留给谁。
4. **长线**：供电上限被塔占满了——是造发电机（花钱占格子），还是留空闲供电给储能充电、换超载爆发。

### 2.2 一局结构（每图 20 波）

| 阶段 | 波次 | 内容 |
|---|---|---|
| 开局 | 1–5 | 单出怪口（图 3 除外），资源只够 3–4 座基础塔，逐波解锁图纸（兼教学/复习） |
| 中段 | 6–14 | 波 10 重构点：第二出怪口开启 + 破阵敌人成建制，逼玩家用挖沟/搭桥/卖塔重排；电力开始不够分 |
| 收尾 | 15–20 | 波 15 小 Boss（修理母舰），波 16–19 混合大潮，波 20 大 Boss 利维坦 |

胜利结算 = 核心完整度换星级（见第 10、13 章）。

## 3. 世界观（每条设定都服务机制）

**末世废土上最后一座地热发电站。** 玩家是电站的值班工程师；敌人是被野蛮 AI 驱使的拾荒机械虫群，来拆电站换零件。维修班组长「老周」是电台里的声音——他负责登场欢迎、大招倒计时播报和丢区警告，**不是可操作单位**（v1 范围锁，见第 4 章）。

| 设定 | 服务的机制 |
|---|---|
| 发电站 | 双资源里的「电」有叙事根：塔是接进电网的设备，占供电上限天经地义 |
| 值班工程师 | 挖沟、搭桥、修复核心完整度都是「工程作业」，有施工时间，不违和 |
| 废土地热区 | 地图天然有水洼（导电 combo 地形）、沟壑（搭桥对象）、软土（挖沟对象）、地热裂隙（图 3 特色地形） |
| 机械虫群 | 敌人「拆塔、修同伴」行为合理；Boss 是巨型采掘机 |
| 漏怪 | 虫子抢走物资（掉金币）、咬断馈线（丢变电区断电），而不是「公主死了」 |

美术基调见第 15 章修订版：斜俯视 2.5D 低模三维场景，锈铁废土上一切「电」皆真实发光。

## 5. 地图与改路

### 5.1 通用网格规则

- 网格 20×12 格。格子类型：
  - **路面**：敌人可走，不可建塔；水洼是路面变体（踩过获「湿」标签 6s）。
  - **地基**：可建塔，不可走。
  - **软土**：不可走不可建，**可挖沟**；与路面重叠的标记为「可挖路段」。
  - **沟壑 / 水面**：不可走不可建，**可搭桥**（桥 = 路面）。
- **挖沟**：把 1 格「可挖路段」变沟壑。每次 50 金，施工 3 秒（施工期间仍可通行）。
- **搭桥**：把 1 格沟壑/水面变路面。每次 80 金。用途：给敌人开一条**你想让它走**的路（引进杀伤区、引过水洼旁的特斯拉阵）。
- **合法性规则**：任何工程操作后，每个出怪口到核心必须仍有通路，否则按钮变红禁止（堵路靠「绕远」实现，不许彻底堵死）。
- **寻路**：地面敌人走当前可通行格的最短路（flow field，从核心反向刷）；地形变化全量重算。飞行敌人直线飞，无视一切。
- **对抗**：爆破工兵会炸玩家搭的桥（次数不返还），改路是持续博弈。

### 5.2 三张地图（各自的教学职责与独特地形）

| | 图 1「主厂房」 | 图 2「冷却水渠」 | 图 3「采掘场边缘」 |
|---|---|---|---|
| 职责 | 教学图：完整教会核心循环与 4 combo | 专项考核：导电流、对空、搭桥引怪 | 综合毕业考：双线运营 + 利维坦 |
| 出怪口 | 1 个，波 10 开第 2 个 | 1 个，波 8 开第 2 个（提前） | **开局即 2 个**，波 12 开第 3 个 |
| 工程次数 | 挖沟 3 / 搭桥 2（波 15 补发挖沟 1） | 挖沟 2 / 搭桥 **3**（波 15 补发搭桥 1） | 挖沟 3 / 搭桥 3（波 15 补发各 1） |
| 独特地形 | 标准配比：少量水洼、可挖路段多、1 条沟壑 | **水渠格**：大面积水洼路面 + 纵横水面；「泄洪道」路段每波开始冲走上面的油渍（油火在此失效，逼玩家转导电） | **地热裂隙格**（4 处）：相邻的发电机供电 +2；沟壑纵横，搭桥价值最大化 |

## 6. 双资源经济（数字初稿，均可调）

### 6.1 金币（一次性开销）

- 获得：击杀赏金 3–12/只；波结束奖励 = 波号 × 5；提前开波 +10% 本波奖励。
- 赏金递减系数：波 10 后 ×0.8，波 15 后 ×0.6（防后期经济爆炸）。
- 花费：建塔、升级、发电机、挖沟（50）/搭桥（80）、波间修复核心（100 金 = +20 完整度）。
- 卖塔返还 70% 现价。起始金币 220。

### 6.2 电力（两层）

- **供电上限**：基础 8 点，每台发电机 +6（图 3 裂隙相邻发电机 +8）。塔**常驻占用**电力，超上限禁止建造/激活。
- **储能（0–100）**：按「空闲供电」充电——每点未被塔占用的供电，每秒给储能 +0.25。储能用于电容站超载（每次 20）。

### 6.3 双资源互相打架的三处设计（刻意为之）

1. 发电机花金币、占地基格——多一台发电机 = 少一个塔位 + 少 100 金。
2. 塔把供电占满，储能就充不动——**火力铺满 vs 保留爆发**是常驻抉择。
3. 丢变电区直接扣供电上限——漏怪的惩罚会逼你卖塔，滚动压力但不即死。

### 7.1 塔表（7 塔 + 1 建筑，数字初稿可调）

|---|---|---|---|---|---|

| 焦油喷洒器 | 70 | 0 | 射程内路面铺油渍（12s），踩中减速 30% + 油标签 | ✗ | 黏稠（减速 40%）/ 大范围 |
| 液压破碎锤 | 120 | 1 | 近程（1.5 格）重击 45 伤/2.5s | ✗ | 震荡波（1 格溅射）/ 快速循环（1.8s） |
| 冷凝喷射塔 | 130 | 2 | 锥形喷雾，无伤害，叠「湿冷」层并附「湿」标签 | ✗ | 冻结 2.5s / 双喷口 |
| 火焰喷射塔 | 140 | 2 | 锥形持续 8 DPS，点油、造火场 | ✗ | 火场延长至 8s / 射程 +1 |
| 特斯拉线圈 | 200 | 4 | 链式闪电 25 伤，链 3 跳（每跳 −30%） | ✓ | 链 5 跳 / 超载后不过热 |
| 电容站 | 160 | 0 | 不攻击；储能上限 +30、充能 ×1.5；主动超载周围 3×3 耗电塔 | — | 超载 8s / 过热减半 |
| 发电机（建筑） | 100 | — | 供电上限 +6 | — | 无升级 |

### 7.2 状态标签规则（防乱炖立法）

- 敌人身上**涂层唯一**：湿 / 油互斥，后者覆盖前者。
- 冻 / 燃是「反应态」，互斥且互相清除。
- 全部 combo 走一张数据驱动反应表（见第 17 章），不写硬编码分支。

### 7.3 四个 combo：触发条件与手感

1. **冰碎**：冷凝塔每 0.5s 叠 1 层「湿冷」，3 层 → 冻结 2s（冻结结束后 3s 免疫叠层，防无限冻）。冻结目标被任何**单发 ≥40 伤**的攻击命中 → **碎裂：250% 伤害 + 1 格溅射，无视护甲，解除冻结**。手感：冰壳白色高亮 + 玻璃碎裂音 + 顿帧 60ms。
2. **油火**：带油标签的敌人被火焰命中 → **点燃（8 伤/s × 4s，刷新不叠加）**；火焰扫过油渍格 → 该格变**火场 5s**，过路敌人点燃。反 combo 教学：火焰打冻结目标会**解冻且伤害 −50%**（冰火不容，UI 一次性提示）。
3. **导电**：带「湿」标签（被冷凝喷过 / 踩过水洼）的敌人被特斯拉命中 → **链跳 +2 且伤害不衰减**。手感：电弧变粗变青，链上所有目标同帧闪白。
4. **超载**：点击电容站 → 消耗 20 储能，周围 3×3 内耗电塔**攻速 +100% 持续 6s，随后过热停机 3s**。手感：塔体泛红、电表爆表音、结束「跳闸」声。停机惩罚让超载是时机题不是无脑按。

### 8.2 利维坦三阶段

- **P1 装甲板**：受伤 −50%；被碎裂命中打落一块装甲板，碎裂对它 ×4（冰碎是解题钥匙但非唯一）。
- **P2（≤50% HP）**：沿途释放 6 只爆破工兵拆塔。
- **P3（≤25% HP）**：过载冲刺——速度 ×2、免疫减速与冻结、每秒自损 30 HP。提示玩家把大招和超载留到这里。

## 9. 大招「主控过载」（无英雄版）

- **效果**：手动释放，全场生效——所有耗电塔立即超载 6s（不耗储能、不过热），同时全场敌人被 EMP **停顿 1.5s**。
- **充能**：每完成 5 波获得 1 次，最多**存 2 次**（防囤到通关）。
- **操作深度全在时机**：留给拆迁蟹潮？留给利维坦 P3 冲刺？停顿 1.5s 给冷凝塔白嫖一轮冻结？
- **演出**：老周电台倒数播报「全网过载，三、二、一——」，从核心扩散电磁波环扫过全图（见第 15 章）。
- 明确不做：第二个大招、大招升级、大招绑定任何单位。

## 10. 胜负、完整度、丢区

- **核心完整度 100 点**。漏怪按敌人表扣分，同时每只漏怪抢走 10 金币（金币粒子被怪吸走的演出）。
- **≤80**：丢 A 变电区——一片地基格断电（区内耗电塔停机、禁新建），供电上限 −4。
- **≤50**：丢 B 变电区——供电上限再 −6，且敌人获得一条更短支路（原被闸门封锁的路打开）。
- **≤0，或利维坦抵达核心**：真正 Game Over。
- 丢掉的变电区本局不可赎回（惩罚可读，v1 不做夺回）。
- 波间可花 100 金修复 +20 完整度，但**修不回已触发的丢区**。
- **胜利**：撑过 20 波。星级 = 完整度 ≥80（3 星）/ ≥50（2 星）/ >0（1 星）。

## 11. 第一关前 5 波教学（无英雄版，零说明书）

- **部署期**：只解锁机枪；两个地基格发光；金币恰好够 2 座。教：放塔、射程圈。
- **波 1**：8 只拾荒虫。必赢，建立「击杀 = 金币」直觉。
- **波 2**：疾行鼠群，纯机枪必漏 2–3 只 → 亲身体会「漏怪只是扣完整度和金币，不是死」。漏怪时老周电台一句吐槽（文字气泡 + 无线电杂音）。波末解锁焦油塔，金币恰好够。教：减速、涂层、完整度条。
- **波 3**：装甲运输车，机枪刮痧（飘「−5」灰字）。解锁发电机 + 冷凝塔 + 破碎锤，供电条首次亮起。敌人首次被冻住时**全局慢放 0.5s + 高亮破碎锤图纸 + 一次性提示条「冻结的敌人怕重击」**——玩家自己造出破碎锤打出第一次碎裂，教学的高潮是玩家的操作而不是演出。教：电力、冰碎。
- **波 4**：3 只侦察蜂直飞核心。建塔菜单里对空图标闪烁；机枪即可解题（不逼买特斯拉）。教：看对空标记、看下一波预览。
- **波 5**：演出：虫群炸开侧墙，出怪口临时切到支路。系统赠送 1 次免费挖沟并高亮推荐格——挖掉支路捷径，怪被引回主杀伤区。波末大招充能满，图标脉冲 + 老周电台报「主控室随时待命」。教：改路、大招存在。

油火与导电不塞进前 5 波：波 6 首次出现「油渍 + 火焰塔图纸」组合关卡节拍，波 8 水洼旁解锁特斯拉，各配一次性提示条。**教学原则：每波只教一件事，教学即解锁节奏。**

## 15. 视觉 / VFX

### 15.1 画面技术路线（锁定）

**2.5D 斜俯视低模三维场景 + 三维单位 + GPU 粒子 + 自发光驱动的灯光氛围。** Unity URP 实现。

- **摄像机**：透视，FOV 30°、俯角 55°、朝向固定不可旋转，缩放两档。逻辑仍是纯 2D 网格，仅表现层 3D。
- **单位与场景**：全部低模网格，平面着色 + 统一色板贴图 + 自发光遮罩。不用像素精灵。
- **灯光**：1 盏固定方向光 + 动态点光全局上限 8 盏（电弧、火场、Boss 专用）；超预算的「光」用加法混合面片伪造；AO 烘焙进贴图。
- **后处理三件套**：Bloom（高阈值只吃自发光）、事件驱动 Vignette（丢区/大招染色）、轻量色调映射。没了。

**美术基调（正式表述）**：斜俯视 2.5D 低模三维场景，平面着色的锈铁废土之上，一切「电」皆真实发光——电弧、超载塔与火场是场景中唯一的光源语言；粒子承担战场信息（四大 combo、断电、施工各有专属色与形状），Bloom 只吃自发光。固定光照、无昼夜。

### 15.2 粒子语言表

**颜色立法**：电青 #35E0FF（电力/导电/超载/大招）· 橙红 #FF7A29（火/自爆）· 冰白 #BFF7FF（冰/碎裂）· 焦褐 #6B4A2B（油渍/尘土）· 金黄 #FFD84D（金币）· 警红 #FF3B30（丢区/核心受损）。

### 15.3 粒子预算（程序约束）

- 同屏活跃发射器 ≤ 64（循环 ≤ 24，一次性 ≤ 40）；超限按「事件 > combo > 环境氛围」丢弃最低级。
- GPU 粒子总量 ≤ 20,000；全部 GPU 模拟（VFX Graph），CPU 粒子零使用。
- 粒子材质 ≤ 12 种，全取自 1 张 1024×1024 图集，保证合批。
- 对象池：命中火花、碎裂、点燃、金币流、自爆等高频一次性效果预热 8–16 实例，运行期零 Instantiate；闪电 LineRenderer 同池。
- 贴花上限 64 张（油渍/霜痕/焦痕/电纹/警戒线共用 atlas），超出淘汰最旧。
- 未达 60fps 时降级顺序（预先立法）：环境氛围粒子 → 循环特效发射率 → 贴花上限 → 动态点光数。**事件类 combo 粒子永不降级。**

## 17. 技术架构与模块开发顺序

### 17.1 最小数据结构（全部配表驱动，JSON/CSV）

```text
Cell        { terrain, coating(none/oil/fire + 剩余时间), zone_id, walkable, buildable }
TowerDef    { id, cost, power_cost, range, damage, fire_interval, targets_air, tags, upgrades[2] }

ReactionRow { 状态标签 × 触发源 → 效果 }          // 4 个 combo 全在这张表里

              ability_charges, dig_left, bridge_left }
Profile     { map_stars[3], codex_seen[], settings }  // 唯一跨局存档
```

### 17.2 系统模块（即开发顺序）

1. **网格与地形**：Cell 数组、地形/涂层渲染、格子查询。
2. **寻路**：从核心反向 BFS 生成 flow field；挖沟/搭桥/丢区时重算；含「堵死校验」。飞行单位不走该系统。
3. **波次生成器**：读 WaveDef 按 gate 出怪，套 MapDef 乘区；下一波预览 UI 从同一份数据出。
4. **战斗**：塔索敌（首位/最强/对空过滤）、即时判定为主（喷雾/电弧），仅机枪用简单弹道。
5. **状态与反应系统**：敌人标签数组 + 数据驱动反应表——4 个 combo 不写 if-else。
6. **经济与电力**：金币收支、供电上限校验、空闲供电→储能的每帧结算。
7. **工程操作**：挖沟/搭桥合法性校验、施工计时、次数管理。
8. **大招与超载**：充能计数、全场/区域效果施加、过热计时。
9. **完整度与区域**：扣分、阈值触发丢区（改 zone 供电状态 + 开支路）。
10. **UI**：第 14 章全部件；combo 一次性提示管理。
11. **关卡数据**：3 张 MapDef + 波表纯配表，无硬编码。
12. **VFX 系统**：GPU 粒子池 + 贴花管理 + 屏幕冲击节流器（顿帧/震动/闪光统一入口）。
13. **音频**：事件音效表 + BGM 双 stem 淡入淡出。
14. **存档与关卡流程**：Profile 读写、星级结算、地图解锁。

不需要：ECS 大架构、网络、局内存档、模组接口。

## 19. 制作里程碑（按可玩版本切）

### M1 垂直切片——「冰碎能爽到」

- **范围**：灰盒图 1 前 10 波；4 塔（机枪/焦油/冷凝/破碎锤）+ 发电机；电力双层；冰碎 1 个 combo 完整（含粒子+音效+顿帧）；挖沟；完整度扣分（无丢区）。
- **验收（可测试）**：
  - 60fps 恒定于参照机；
  - 内部试玩 5 人：≥4 人无口头引导通过波 5，且能复述冰碎触发规则；
  - 冰碎首次触发的「看+听」反馈链（慢放/提示条/粒子/音效）全部触发无遗漏；
